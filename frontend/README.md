# CampusHub Frontend

CampusHub 前端项目，基于 React + TypeScript + Vite。

## 技术栈

- React 19
- TypeScript 5
- Vite 8
- ESLint 9

## 目录结构

- src/: 页面与组件源码
- src/assets/: 静态资源
- public/: 公共静态资源

## 开发环境

请先安装 Node.js 20+。

## 常用命令

在 frontend 目录下执行：

```bash
npm install
npm run dev
```

## 构建与预览

在 frontend 目录下执行：

```bash
npm run build
npm run preview
```

## 代码检查

在 frontend 目录下执行：

```bash
npm run lint
```
