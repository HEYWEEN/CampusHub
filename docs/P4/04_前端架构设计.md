## 四、状态管理

### 4.1 Zustand Stores（客户端状态）

```ts
// src/stores/auth.ts
useAuthStore: {
  userId: string | null
  accessToken: string | null
  refreshToken: string | null
  verifyStatus: 'guest' | 'pending' | 'approved' | 'rejected'
  login(tokenPair) / logout() / setVerifyStatus()
}

// src/stores/credit.ts  
useCreditStore: {
  score: number          // 信用分
  pointBalance: number   // 可用积分
  pointFrozen: number    // 冻结积分
  canPublish: boolean    // 信用 >= 60
  canAccept: boolean     // 信用 >= 60
  dailyAcceptLimit: number // 每日接单上限
  refresh() → GET /api/credits/me
}

// src/stores/notify.ts
useNotifyStore: {
  unreadCount: number    // header badge 用
  refresh() → GET /api/notify/messages/unread-count
}
```

### 4.2 TanStack Query（服务端数据）

所有列表 / 详情 / 列表数据走 react-query：
- 自动缓存 + 失效（mutation 后 invalidate）
- 自动重试 / loading / error 状态
- queryKey 规范：`['task', taskId]` / `['tasks', searchParams]`

## 五、API Client

### 5.1 拦截器

```ts
// src/api/client.ts （Axios 实例变量名为 instance，默认导出）
instance.interceptors.request → 注入 Authorization: Bearer ${accessToken}
instance.interceptors.response →
  - 自动解包 ApiResponse<T>，调用方拿 T
  - code != 0 → throw BizError(code, message)
  - 401 → 直接 logout → 跳 /login（无 refresh token 重试逻辑）
  - 网络错误 / 5xx → 同样 throw BizError（携带 httpStatus 字段，供 withMock 判断是否回退 mock）
```

### 5.2 文件结构

```
src/api/
├─ client.ts        ← Axios 实例
├─ auth.ts          ← sendSmsCode / loginByCode / loginByPassword / register
├─ task.ts          ← createTask / getTask / acceptTask / submitProof / confirm + searchTasks（无独立 search.ts）
├─ trade.ts         ← 商品/订单/砍价 offer + searchItems
```
