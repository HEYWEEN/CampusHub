## 2. 图例（UML 关系）

| 记号 | 含义 |
| :--- | :--- |
| `..|>` | 实现（implements） |
| `--|>` | 继承（extends） |
| `-->` | 关联依赖（调用、注入） |
| `*--` | 组合（强拥有，如 Context 持有 State） |
| `o--` | 聚合（弱拥有，如 Task 持有 Attachment 列表） |
