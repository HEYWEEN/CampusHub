# P3 功能映射主表（Functional Mapping Master Table）

> **目的：** 横向分工下，让"类图 / API / ER+SQL"三视角在**同一行**对齐。
> **使用方式：**
> 1. 组长**已填**：功能 ID、用户故事/SRS、模块、关键规则。
> 2. 组员**待填**（按交付物分工）：
>    - **A（类图负责人）** 填 _涉及类_ 列
>    - **B（API 负责人）** 填 _API 接口_ 列
>    - **C（ER+SQL 负责人）** 填 _涉及表_ 列
>    - **D（整合负责人）** 负责追踪每行三列是否都填齐，发现冲突拉会
> 3. 任何一行三列填完后，互审签字（在"互审"列写姓名）。
> 4. **整合阶段**直接基于本表逐行对账，不允许遗漏或新增。
> **图例：** ✓ = P0（Must） / ★ = P1（Should） / ◇ = P2（Could） / ✗ = Won't（本期不做，记录但不实现）

---

## 总览

- **功能总数：** 65（P0：38 / P1：21 / P2：4 / Won't：2）
- **覆盖模块：** 11 + 1 跨模块共用（auth / user / task / trade / edu / team / im / notify / credit / report / admin / search）
- **覆盖用户故事：** US-01 ~ US-20（共 20 条）
- **完成判据：** 每行三列必填；P0 行必须互审通过；P1/P2 行可标"延后"。
