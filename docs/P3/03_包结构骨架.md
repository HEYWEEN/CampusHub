## 4. 业务模块标准结构（设计期模板）

> **实现差异说明**：下方 `task/` 为设计期统一模板，**真实分布以 §4.1 表为准**。实际差异——`search`/`wall` 为空骨架；`admin` 无 entity/repository（管理员靠 `auth_user.role`）；`recommend` 仅 controller/model/service；`agent` 含非标准 `client`/`tool`/`config` 子包；`credit` 无独立 `CreditService`（`CreditController` 直接注入 `CreditServiceImpl`，跨模块能力经 `CreditApi`）；`exception/` 多为单个 `XxxErrorCode` 枚举（下方模板里的 `TaskAlreadyAcceptedException` 等独立异常类**未实现**，统一用 `TaskErrorCode` + `BizException`）；`api/` 仅 user/task/notify/credit 四个模块有；`TaskAdminController` 未实现（管理端 task 接口未做）。

### 4.2 跨模块订阅（`listener` 子包）

`notify` 和 `credit` 是事件主要订阅方，举例：

原设计：
```
notify/listener/
├── TaskEventListener.java              # 监听 TaskAcceptedEvent / TaskCompletedEvent
├── ReportEventListener.java            # 监听 ReportSubmittedEvent
└── UserVerifiedEventListener.java

credit/listener/
├── TaskEventListener.java              # BEFORE_COMMIT 冻结/解冻/结算
└── BadReviewEventListener.java         # BEFORE_COMMIT 扣分
```

> **实现对齐**：实际 `notify/listener/` 仅 `TaskEventListener`；`credit/listener/` 为 `TaskEventListener` + `TradeEventListener`（无 ReportEventListener/UserVerifiedEventListener/BadReviewEventListener）。且全部用同步 `@EventListener`（非 BEFORE_COMMIT，见 01 规约 INV-04 已知取舍）。

```
        ├── PublicUserVO.ts
        ├── TaskDetailVO.ts
        └── ...
```

**前端规约要点：**
- 所有 API 调用走 `api/client.ts`，**禁止**在组件里直接 `fetch`
- TS 类型放 `types/`，命名与后端 VO/DTO 一致（`TaskDetailVO`）
- 隐私字段黑名单同样适用：组件内不允许 access `realName / studentNo`
- 学生端和管理端是**两个 SPA 还是同 SPA 双路由**？由前端负责人在 P3 阶段决定，本骨架按"同 SPA + `/admin/**` 路由前缀"组织

## 9. 一键创建骨架（参考脚本）

```bash
#!/usr/bin/env bash
# scripts/scaffold-p3.sh — 一次性创建后端 11 个模块的标准目录
set -e

BASE="backend/src/main/java/com/campushub"
MODULES=(auth user task trade edu team im notify credit report admin search wall)
SUBPKGS=(api controller service repository entity dto vo event exception)

mkdir -p "$BASE/common"/{response,exception,util,enums,interceptor}
mkdir -p "$BASE/config"

for m in "${MODULES[@]}"; do
  for s in "${SUBPKGS[@]}"; do
    mkdir -p "$BASE/$m/$s"
  done
done

# 特殊子包
mkdir -p "$BASE/task/state" "$BASE/task/scheduler"
mkdir -p "$BASE/credit/strategy" "$BASE/credit/listener"
mkdir -p "$BASE/notify/listener"
mkdir -p "$BASE/report/scheduler"

mkdir -p backend/src/main/resources/db/migration
mkdir -p docs/P3/{类图,API,数据库,AI-prompt}

echo "P3 骨架创建完成。"
```

> ⚠️ **空目录 Git 不会跟踪**，建议每个目录放一个 `.gitkeep` 或 `package-info.java`。
