## 2. `common/`（跨模块共享，全员只读）

**严禁** 在 `common` 里放业务代码。只放纯技术工具。

```
common/
├── response/
│   ├── ApiResponse.java                # { code, message, data, traceId } 包装
│   ├── PageResponse.java               # { items, total, page, size }
│   └── ResponseCode.java               # 通用错误码枚举
├── exception/
│   ├── BizException.java               # 业务异常基类（带 code + message）
│   ├── GlobalExceptionHandler.java     # @RestControllerAdvice 全局处理
│   └── NotFoundException.java          # 404
├── util/
│   ├── JwtUtil.java
│   ├── PhoneMaskUtil.java              # 138****1234
│   ├── ExifCleaner.java                # 图片 EXIF 清洗（trade/wall 共用）
│   ├── AesUtil.java                    # 列加密
│   └── TraceIdHolder.java              # ThreadLocal traceId
├── enums/
│   ├── VerifyStatus.java               # PENDING / APPROVED / REJECTED
│   └── BaseEnum.java                   # 枚举存储基类
```

**ArchUnit 规则示例（`test/archunit`）：**
- `common.*` 不允许 import 任何 `<module>.*`
- 任何 `controller.*` 出参类必须以 `VO` 结尾或位于 `common`

**前端规约要点：**
- 所有 API 调用走 `api/client.ts`，**禁止**在组件里直接 `fetch`
- TS 类型放 `types/`，命名与后端 VO/DTO 一致（`TaskDetailVO`）
- 隐私字段黑名单同样适用：组件内不允许 access `realName / studentNo`
- 学生端和管理端是**两个 SPA 还是同 SPA 双路由**？由前端负责人在 P3 阶段决定，本骨架按"同 SPA + `/admin/**` 路由前缀"组织

## 9. 一键创建骨架（参考脚本）

```bash
#!/usr/bin/env bash
# scripts/scaffold-p3.sh — 一次性创建后端 11 个模块的标准目录
set -e

BASE="backend/src/main/java/com/campushub"
MODULES=(auth user task trade edu team im notify credit report admin search wall)
SUBPKGS=(api controller service repository entity dto vo event exception)

mkdir -p "$BASE/common"/{response,exception,util,enums,interceptor}
mkdir -p "$BASE/config"

for m in "${MODULES[@]}"; do
  for s in "${SUBPKGS[@]}"; do
    mkdir -p "$BASE/$m/$s"
  done
done

# 特殊子包
mkdir -p "$BASE/task/state" "$BASE/task/scheduler"
mkdir -p "$BASE/credit/strategy" "$BASE/credit/listener"
mkdir -p "$BASE/notify/listener"
mkdir -p "$BASE/report/scheduler"

mkdir -p backend/src/main/resources/db/migration
mkdir -p docs/P3/{类图,API,数据库,AI-prompt}

echo "P3 骨架创建完成。"
```

> ⚠️ **空目录 Git 不会跟踪**，建议每个目录放一个 `.gitkeep` 或 `package-info.java`。
